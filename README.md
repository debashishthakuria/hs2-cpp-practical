# Practical C++ · HS 2nd Year study workspace

A concept-first guide to the 15 programs in a photographed practical assignment: learn, plan, trace, reveal Turbo C++-style code, understand it, and practise. Independent student guide, not an official answer key.

## Use

Open `index.html` locally, or visit the GitHub Pages deployment. No build step or CDN is required. Progress stays in this browser's localStorage; search and lesson deep links work in-page. Every program can be downloaded as a `.CPP` file.

## Important limits

The assignment photo has unclear wording in some questions. Interpretations are shown in the relevant lessons; confirm with a teacher. Programs target legacy Turbo C++ syntax (`iostream.h`, `conio.h`, `void main()`). Modern compilers need an adapted copy, not the original program. This site displays programs but does not execute code. Sample answers are illustrative and unofficial.

## Files

- `index.html`, `style.css`, `app.js`: static study interface
- `lessons.js`: all 15 lesson records and original sample programs
- `test-site.cjs`: structural regression check (`node test-site.cjs`)
- `lesson-test-report.txt`: program compile/run verification notes

## Publish

The site is a static GitHub Pages project served from the repository root on `main`. Keep lesson data and checks updated together. No personal data or accounts are collected by the site.
