Employee, Department & Location

Read this before copying SQL

  • The given Employee schema has no Job/role column. Questions 4 and 6 cannot be answered as written. Do not invent one without your teacher’s approval.
  • Question 7 says emp and ename, while the sheet defines Employee, Fname and Lname. The suggested answer uses the declared names.
  • Question 8 does not specify an employee-level manager relationship. The suggested join uses the department’s Mngrno; confirm this interpretation.

  • Examples below use MySQL-style SQL. Q10’s MODIFY syntax is MySQL-specific. Your lab may use another DBMS.

Start with the tables

Sheet: Employee (Fname, Lname, Empno, Bdate, Address, Salary, Dnumber); Department (Dname, Dnumber, Mngrno); Location (Dnumber, DLocation). The types, primary keys and sample values below are illustrative choices, not printed in the assignment.

Reveal the table definitions and sample records
CREATE TABLE Employee (
  Fname VARCHAR(30), Lname VARCHAR(30), Empno INT PRIMARY KEY,
  Bdate DATE, Address VARCHAR(80), Salary DECIMAL(10,2),
  Dnumber INT
);
CREATE TABLE Department (
  Dname VARCHAR(40), Dnumber INT PRIMARY KEY, Mngrno INT
);
CREATE TABLE Location (
  Dnumber INT, DLocation VARCHAR(40),
  PRIMARY KEY (Dnumber, DLocation)
);

Queries from the sheet

Read each task first; reveal a suggested answer only after attempting it. Wording is lightly spaced for readability; apparent schema mismatches are called out rather than silently repaired.

1. Display the records of employee table.

Show suggested query
SELECT * FROM Employee;

Start here; the assignment marks question 1 compulsory.

2. Display employees working in department 20.

Show suggested query
SELECT * FROM Employee WHERE Dnumber = 20;

Filter rows by the department number stored on each employee.

3. Display employees in descending salary order.

Show suggested query
SELECT * FROM Employee ORDER BY Salary DESC;

DESC places the largest salary first.

4. Display the count of different jobs in employee table.

Blocked by the printed schema: Employee has no Job column. Ask whether a Job/role attribute was omitted.

Show conditional example only if Job is added
-- ONLY if your teacher adds Employee.Job:
SELECT Job, COUNT(*) AS EmployeeCount
FROM Employee GROUP BY Job;

This gives a count per job. If the task instead means the number of distinct job titles, use COUNT(DISTINCT Job).

5. Minimum, total and average salary of each department.

Show suggested query
SELECT Dnumber, MIN(Salary) AS MinimumSalary,
       SUM(Salary) AS TotalSalary,
       AVG(Salary) AS AverageSalary
FROM Employee GROUP BY Dnumber;

Aggregate separately for each Dnumber.

6. Details of employees working as ‘Manager’.

Ambiguous: there is no Job column. If “Manager” means the employee referenced by Department.Mngrno, use this interpretation; it does not prove their job title is Manager.

Show department-manager interpretation
SELECT DISTINCT E.* FROM Employee AS E
JOIN Department AS D ON E.Empno = D.Mngrno;

7. Display empno, ename, salary from emp with salary between 15000 and 20000.

The sheet’s emp and ename do not exist in its declared schema. The query uses Employee and both name columns.

Show query using declared columns
SELECT Empno, Fname, Lname, Salary FROM Employee
WHERE Salary BETWEEN 15000 AND 20000;

BETWEEN includes both endpoints.

8. List employee names with their manager’s name, where names start with ‘R’.

Interpreted here as manager names beginning with R, using each department’s Mngrno. The sheet does not say whose names the R condition applies to.

Show interpreted join
SELECT E.Fname AS EmployeeName, E.Lname AS EmployeeLastName,
       M.Fname AS ManagerName, M.Lname AS ManagerLastName
FROM Employee AS E
JOIN Department AS D ON E.Dnumber = D.Dnumber
JOIN Employee AS M ON D.Mngrno = M.Empno
WHERE M.Fname LIKE 'R%';

If the teacher means employee names, change the condition to E.Fname LIKE 'R%'.

9. Change the name of the employee whose number is 10 to Amar.

Show suggested query
UPDATE Employee SET Fname = 'Amar' WHERE Empno = 10;
SELECT Empno, Fname, Lname FROM Employee WHERE Empno = 10;

This assumes “number” means Empno and “name” means Fname.

10. Alter salary’s data type to numeric.

Show MySQL-specific query
ALTER TABLE Employee MODIFY Salary DECIMAL(10,2);

DECIMAL(10,2) is a numeric type suitable for sample salaries. Syntax varies across database systems.

11. Total, maximum, minimum and average Marketing salary.

Show suggested query
SELECT SUM(E.Salary) AS TotalSalary,
       MAX(E.Salary) AS MaximumSalary,
       MIN(E.Salary) AS MinimumSalary,
       AVG(E.Salary) AS AverageSalary
FROM Employee AS E
JOIN Department AS D ON E.Dnumber = D.Dnumber
WHERE D.Dname = 'Marketing';

12. Retrieve the Administration department’s location.

Show suggested query
SELECT L.DLocation FROM Department AS D
JOIN Location AS L ON D.Dnumber = L.Dnumber
WHERE D.Dname = 'Administration';

13. Names of Finance employees earning more than 20000.

Show suggested query
SELECT E.Fname, E.Lname FROM Employee AS E
JOIN Department AS D ON E.Dnumber = D.Dnumber
WHERE D.Dname = 'Finance' AND E.Salary > 20000;

14. Retrieve the Administration department’s location.

This duplicates question 12 on the photographed sheet; it is not a new task.

Show the same query
SELECT L.DLocation FROM Department AS D
JOIN Location AS L ON D.Dnumber = L.Dnumber
WHERE D.Dname = 'Administration';

15. Perform an equijoin on Employee and Department.

Show suggested query
SELECT E.Empno, E.Fname, E.Lname, D.Dname
FROM Employee AS E
JOIN Department AS D ON E.Dnumber = D.Dnumber;

The equality condition connects matching department numbers. The printed phrase “department the files” is unclear.

Quick revision before the practical

  1. Write the three CREATE TABLE statements and explain each primary key.
  2. Practise WHERE, ORDER BY, GROUP BY and the aggregate functions on the sample data.
  3. Trace the join path: Employee.Dnumber → Department.Dnumber → Location.Dnumber; for managers, Department.Mngrno → Employee.Empno.
  4. Ask your teacher about the missing Job field, the names in question 7, the R condition in question 8, and the DBMS used in the lab.
