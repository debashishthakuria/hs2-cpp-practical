  3. Matrices: write the addition and multiplication dimension rules before writing any loops.

Sorting

Bubble sort: compare adjacent values and swap when out of order. With 5, 2, 4, the first pass changes the list to 2, 4, 5. Insertion sort: take the next value and insert it into its place in the already sorted left portion.

Practise: trace both methods on 7, 1, 5, 3. Then write one method without looking at the solution. The existing assignment lesson has Turbo C++-style code for both methods.

Searching

Linear search: inspect items one by one until the target is found or the list ends. Keep the found position separate from the target value. Binary search: only on a sorted list, compare the middle item and discard one half at each step.

Practise: find 9 in 4, 9, 2, 8 using linear search; answer: second position (index 1 in a zero-based array). For binary search, first take a sorted list such as 2, 4, 8, 9.

Show Turbo C++ linear-search example
#include <iostream.h>
#include <conio.h>
void main() {
    clrscr();
    int a[20], n, target, i, pos = -1;
    cout << "How many numbers (1-20)? ";
    cin >> n;
    if (n < 1 || n > 20) {
        cout << "Invalid count";
        getch();
        return;
    }
    for (i = 0; i < n; i++) cin >> a[i];
    cout << "Search for: ";
    cin >> target;
    for (i = 0; i < n; i++) {
        if (a[i] == target) { pos = i; break; }
    }
    if (pos == -1) cout << "Not found";
    else cout << "Found at position " << pos + 1;
    getch();
}

Matrix addition and multiplication

Addition: both matrices must have the same number of rows and columns; add matching entries. Multiplication: A’s columns must equal B’s rows. If A is 2 × 3 and B is 3 × 2, AB is 2 × 2, but addition is not possible. Each product entry sums A[i][k] × B[k][j] across k.

Practise: add two 2 × 2 matrices, then multiply them by hand and check your row-by-column calculation. The assignment lesson includes a complete Turbo C++-style example.
